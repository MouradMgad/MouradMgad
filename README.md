## Research Experience

**University of Louisville — Louisville, Kentucky, USA**  
*Summer Research Intern · July–September 2026*

### 01 · EEG Seizure Detection
- Developed an EEG window-prioritization pipeline processing **616 hours** of continuous recordings.
- Reduced the data requiring detailed analysis by **92.5%**, retaining **79.6% seizure-event sensitivity**.
- Built a feature-extraction and XGBoost classification workflow.

### 02 · CardioScreen — Heart-Sound AI
- Built a complete heart-sound classification pipeline using **3,240 recordings**.
- Engineered **301 signal features** using MFCCs, spectral statistics, and wavelet transforms.
- Achieved **93.6% accuracy** and **0.975 AUROC** on a held-out test set.

### 03 · Brain–Computer Interfaces
- Adapted the **MIRepNet** EEG model to 15-channel OpenBCI recordings.
- Implemented signal preprocessing, resampling, Euclidean Alignment, spatial interpolation, and transfer learning.
- Achieved approximately **79% macro accuracy** under strict held-out-participant evaluation.
- Developed an SSVEP-based directional-control experiment.

### 04 · BCI & Robotics Research
- Conducted a structured review of brain–computer interfaces for robotic systems.
- Organized evidence from **1,838 initially identified records** into a structured research taxonomy.
